## Các hợp đồng phải giữ

- React + TypeScript + Vite; Python FastAPI/Uvicorn; SQLite; một instance/worker.
- OpenRouter adapter đầu tiên. Credential chỉ phía server; không đưa key vào repo/chat/snapshot/export.
- Quality: director structured selection → validated ids → narrator. Economy: deterministic selection → narrator.
- Mặc định unconfigured/economy/free_only; không fallback sang paid/provider/mode khác.
- Input cấu hình 12.000, tổng output 4.000 gồm reasoning, wrapper 512; effective input = min(input cấu hình, verified window − output − wrapper).
- Giới hạn USD là tổng hai stage; tách provider billing/calculated/estimated/unknown, unknown không tính là 0.
- Tối đa 2 physical attempt, timeout mặc định 300s; slot giữ tới khi thread provider thật dừng.
- Reconnect đọc job/key/event cursor, không gửi lại generation. Offset là UTF-16 code units.
- Canon, scene, knowledge, persona agency và StyleProfile có phiên bản/provenance. Summary thay raw phải giữ coverage; latest pair giữ raw.
- Candidate hoàn chỉnh mới commit; stale/incomplete/refused/truncated không auto-commit.
- Local test trước. Domain dự kiến `play.nhkhuy.run.place`, **Caddy**; SSH/DNS/VPS sau.
- Whif chỉ tham khảo client/UX qua APK; không claim biết backend và không đưa assets/APK vào repo.
- Mẫu playrooom chỉ có phần đã xác minh; không invent lịch sử đầu.
