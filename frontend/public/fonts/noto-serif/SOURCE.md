# Noto Serif reading fonts

Source: Google Fonts `ofl/notoserif`, pinned revision
`8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`:

- https://github.com/google/fonts/blob/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoserif/NotoSerif%5Bwdth%2Cwght%5D.ttf
- https://github.com/google/fonts/blob/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoserif/NotoSerif-Italic%5Bwdth%2Cwght%5D.ttf

Licensed under SIL Open Font License 1.1; the unmodified license is in `OFL.txt`.
These WOFF2 files are Unicode subsets of the upstream variable fonts, generated
with FontTools and Brotli, keeping all OpenType layout features, pinning width to
100% and limiting the variable weight axis to 400–700.
Included ranges: `U+0000-024F`, `U+0300-036F`, `U+1E00-1EFF`, `U+2000-206F`,
`U+20AB`. This includes Vietnamese composed letters, decomposed combining marks,
Latin text and common punctuation. CSS uses normal/italic weights 400–700.

Assets are served by Playroom itself; the browser does not contact a font CDN.
FontTools/Brotli are preparation tools, not application or build dependencies.
